**Breast Cancer Classification Suite**



**Project Overview**



This repository demonstrates multiple Machine Learning approaches for breast cancer prediction using the Breast Cancer Wisconsin dataset.



The project compares classification algorithms and dimensionality reduction techniques.



**Technologies Used**



\* Python

\* Pandas

\* NumPy

\* Matplotlib

\* Seaborn

\* Scikit-Learn

\* XGBoost



**Models Implemented**



\* Logistic Regression

\* Support Vector Machine (SVM)

\* XGBoost Classifier

\* Principal Component Analysis (PCA)



**Workflow**



1\. Data Loading

2\. Exploratory Data Analysis

3\. Feature Engineering

4\. Dimensionality Reduction

5\. Model Training

6\. Model Comparison

7\. Evaluation



**Evaluation Metrics**



\* Accuracy Score

\* Confusion Matrix

\* Classification Report



**Business Goal**



Compare predictive performance of multiple ML algorithms for medical diagnosis classification.



**Results**



Successfully implemented and compared multiple classification and dimensionality reduction techniques.
